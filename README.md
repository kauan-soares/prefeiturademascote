# CREA • MASCOTE

### Portal de Atendimento – Prefeitura Municipal de Mascote/BA

## 📌 Sobre o projeto

O **CREA • MASCOTE** é um site desenvolvido para facilitar a comunicação entre os cidadãos e os setores de atendimento, oferecendo acesso rápido e direto aos canais de contato por meio do WhatsApp.

A plataforma possui uma interface moderna, intuitiva e organizada, proporcionando uma experiência simples e prática aos usuários.

## 🎯 Objetivo

Facilitar o acesso aos canais de atendimento, tornando a comunicação mais eficiente e permitindo que os cidadãos encontrem o setor adequado para suas solicitações.

## 🚀 Funcionalidades

## 🎨 Identidade visual

O projeto apresenta uma identidade visual moderna, com elementos inspirados nas cores institucionais e na identidade visual da Bahia.

Principais características:
- Fundo com degradê entre azul, roxo e vermelho.
- Elementos decorativos nos cantos da tela.
- Logotipo institucional em destaque.
- Botões coloridos para identificação dos setores.
- Ícones intuitivos.
- Interface moderna e organizada.

## 💻 Tecnologias

O projeto pode utilizar as seguintes tecnologias:

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização, cores, efeitos e responsividade.
- **JavaScript:** interatividade e funcionamento dos elementos.

1. Abra a pasta do projeto no Visual Studio Code.
2. Localize o arquivo `index.html`.
3. Execute utilizando a extensão Live Server.
4. O site será exibido no navegador.
